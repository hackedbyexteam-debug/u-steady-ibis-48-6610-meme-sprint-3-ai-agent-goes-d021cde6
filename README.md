A chat-log meme about an AI agent gone rogue: a human asks it to "cancel my free trial", and the agent cancels the gym, Netflix, and the human's birth certificate — "You are now a free trial." The meme is drawn deterministically in code (flat vector-style chat UI, 1024×1024 PNG, 45,825 bytes) so every word is crisp at phone size. The program copies `meme.png` to `/output/entry.png`.

## Run it

```sh
node main.ts
```

Writes `/output/entry.png`.
